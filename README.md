# AFTERBURN 🛩️

An endless flight through a dream that never quite resolves. Vanilla Three.js + Vite, no assets — everything procedural, everything synthesized.

**Fly:** mouse steers · **SPACE** boost (meter refills, gates top it up) · **Q/E** barrel roll (brief invulnerability) · thread the neon gates for streak multipliers · dodge the crystal spires (3 shields) · the sky whales are not obstacles, they're company.

The world re-colours itself every ~26 seconds — violet dusk, abyssal teal, ember rose, mint hollow. Best score persists on-device.

```bash
npm install
npm run dev      # local
npm run build    # dist/
```

Append `?fly` to the URL to skip the title screen.
